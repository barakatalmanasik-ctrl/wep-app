# AGENTS.md — قواعد العمل الإلزامية

## المشروع الرئيسي
- مجلد **`pure-app`** هو المشروع الرسمي والوحيد. كل التعديلات والإضافات والإصلاحات تتم هنا فقط.

## ممنوع نهائياً
- لا تقرأ، لا تعدّل، لا تنشئ، ولا تستخدم كمصدر للكود أي ملفات داخل:
  - `barakat_account`
  - `electron-app`
  - `web-app`
- لا تنسخ الملفات بين `pure-app` وهذه المجلدات، ولا تزامن أي تعديلات معها، إلا بطلب صريح من المستخدم.
- الملفات المكررة الموجودة في المجلدات الأخرى تُتجاهل تماماً.

## التشغيل والاختبار والنشر
- التشغيل والاختبار والبناء (Build) والرفع إلى GitHub والنشر على الاستضافة يتم باستخدام `pure-app` فقط.
