## [15.1.0] — 2026-08-06

### خدمة «قطع» متعددة الخدمات
- **جديد:** زر «قطع» يفتح قائمة منسدلة بـ 4 خدمات: قطع تذكرة طيران / إصدار فيزا / حجز فندق / شراء شريحة eSIM
- **جديد:** نافذة نموذج موحدة للخدمات الجديدة (فيزا / فندق / eSIM) بنفس بنية نافذة التذكرة
- **جديد:** سعر البيع يُترك فارغاً في الحجوزات — يُملأ يدوياً لاحقاً، مع حساب الربح تلقائياً عند إدخاله
- **تحسين:** إزالة شرط «الرصيد غير كافٍ» — الرصيد يُسمح له بالسالب عند تجاوز التكلفة
- **جديد:** شارات مميزة لكل خدمة في كشف الحساب وآخر العمليات (تذكرة/فيزا/فندق/eSIM)
- **جديد:** Migration V13 — إضافة حقول `serviceType` و`bookingRef` و`pnr` + تسجيل حجوزات الطيران القائمة (FL-429571، FL-7E5C79، FL-58C41A) بتكلفتها وسعر البيع فارغ

- **جديد:** جدول الأقساطwithin صفحة العميل (إضافة/تعديل/حذف)
- **جديد:** `db.clients` — مصفوفة مستقلة للعملاء
- **جديد:** `CLIENT_SCHEMA`، `SERVICE_SCHEMA`، `PAYMENT_SCHEMA` — هياكل موحدة
- **جديد:** `normalizeClient()`، `normalizeService()`، `normalizePayment()` — تطبيع البيانات
- **تحسين:** Migration V2→V3 تضيف `clients: []` تلقائياً
- **تحسين:** النسخ الاحتياطي يشمل جميع بيانات العملاء تلقائياً
